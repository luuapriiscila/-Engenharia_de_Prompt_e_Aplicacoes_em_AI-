Esse código foi desenvolvido com o auxílio do **GitHub Copilot** 💻🤖, que ajudou principalmente na geração da estrutura do jogo, estilização da interface e criação das funcionalidades em JavaScript.

O projeto utiliza:

* **HTML** 🧱 para estruturar as telas e os elementos do jogo;
* **CSS** 🎨 para criar o design, animações e responsividade;
* **JavaScript** ⚡ para controlar toda a lógica do sistema.

### 🎮 Como o jogo funciona

1. O jogador inicia na tela de boas-vindas e informa seu nome 👤.

2. O sistema gera automaticamente operações matemáticas aleatórias ➕➖✖️.

3. Cada pergunta possui um cronômetro de **15 segundos** ⏱️ para resposta.

4. O JavaScript verifica se a resposta está correta:

* ✅ Se acertar, o jogador ganha pontos e o personagem realiza animações;
* ❌ Se errar, o sistema informa a resposta correta.

5. O jogo acompanha estatísticas em tempo real 📊, como:

* quantidade de acertos;
* pontuação;
* tempo médio de resposta;
* taxa de acerto.

6. Após **10 perguntas**, o sistema finaliza a partida 🏆 e exibe um resumo completo do desempenho do jogador.

O **GitHub Copilot** 🚀 foi importante no desenvolvimento por agilizar a criação das funções, sugerir soluções para animações e organização do código, além de auxiliar na construção da lógica do jogo de forma mais rápida, prática e eficiente.
